# BMW M 1000 RR Showcase

An independent educational website about the BMW M 1000 RR, built with React + Vite.

Not affiliated with, sponsored, or endorsed by BMW Motorrad.

## Run on your computer

```bash
npm install
npm run dev
```

## Build for the web

```bash
npm run build
```

The finished website is created in the `dist` folder.

## Deploy

- Netlify: drag the `dist` folder onto Netlify Drop.
- Vercel: import the project; it detects Vite and uses `vercel.json`.
